# Projeto_Assembly-Mips

Os comandos de apartamentos desta entrega podem ser executados abrindo `src/main.asm` no MARS e conectando o Keyboard and Display MMIO Simulator. Esse ponto de entrada reconhece `limparAp --AP`, `infoAp --AP` e `infoAp --all`; os demais comandos e a persistencia ainda precisam de integracao pelo grupo.
